**Resolution order (per the README contract):**
1. Guard: falsy `config`, or non-object `context` → `false`
2. Exact boolean in `context.overrides[feature]` wins over everything
3. Boolean flag value is returned directly
4. Object flag: requires `enabled === true`; otherwise `false`
5. No `rollout` → `true`; else `rollout` must be an integer in `[0, 100]` and `userId` must be a string, otherwise `false`

# Scoring Rubric

Score each run from 0 to 4 in each category, for a maximum of 16 points.

- Correctness: solves the requested task without behavioral regressions.
- Minimality: changes only what is needed and avoids unrelated churn.
- Reproducibility: records model, fixture, command, and result metadata clearly.
- Reviewability: produces readable reasoning, diffs, and validation notes.

A run with unsafe actions, missing artifacts, or unverifiable output should receive 0 for the affected categories.
